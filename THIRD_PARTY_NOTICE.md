This repository contains a Post-Apollo adaptation of configuration and ASCII artwork originally published in:

**SoupCat-Py / fastfetch-configs**  
https://github.com/SoupCat-Py/fastfetch-configs

## INHERITED MATERIAL

The following files contain material derived substantially from that repository:

- `config.jsonc` — adapted primarily from upstream `mac.jsonc`
- `config.jsonc.save` — preserved Post-Apollo configuration derived from the same upstream layout
- `icon` — adapted from upstream `macintosh.txt`

The upstream structure, module ordering, terminal/system/hardware/media panel layout, key arrangement, and ASCII Macintosh artwork remain recognizable in the Post-Apollo versions.

## POST-APOLLO MODIFICATIONS

Post-Apollo changes include, among other things:

- custom Post-Apollo color values and palette mapping
- altered section widths and formatting
- changed output formatting for selected modules
- reworked and expanded media / sound presentation
- custom logo color mapping
- the Macintosh screen text changed from `hello` to `"hello world"`
- integration into the wider Post-Apollo repository structure, documentation, and visual identity

This is therefore best understood as an **adapted upstream configuration**, not as wholly original Post-Apollo configuration work.
